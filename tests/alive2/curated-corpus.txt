# Alive2 curated function corpus for translation validation.
#
# Format: <ori_file_path> [function_name]
#   - If function_name is omitted, all _ori_* functions are verified.
#   - Lines starting with # are comments.
#   - Paths are relative to the repo root.
#
# Selection criteria:
#   INCLUDE: Pure arithmetic, simple control flow, no runtime calls,
#            no invoke/landingpad, no indirect calls (closures).
#   EXCLUDE: Functions with _ori_rc_*, invoke, _ori_alloc, _ori_panic,
#            _ori_is_unique (COW), large loop nests, va_arg.
#   SURVIVAL: Each entry MUST survive -O2 optimization (not inlined away).
#            Verify with: diagnostics/alive2-verify.sh --check-survival <file>
#
# To add entries: write a pure .ori function, build with ORI_ALIVE2_CAPTURE=1
# and --opt=2, verify it appears in both preopt.ll and postopt.ll.
