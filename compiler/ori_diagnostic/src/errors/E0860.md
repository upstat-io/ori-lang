# E0860: `break` with Value in a Void-Typed Loop

A `break value` was used inside a loop form that has type `void` and therefore
cannot produce a value: `while...do` and `for...do`.

## Example

```ori
while cond do {
    if done then break 5  // ERROR: `while...do` does not produce a value
}
```

```ori
for x in items do {
    if x > 100 then break x  // ERROR: `for...do` has type void
}
```

## Explanation

Only `loop { ... }` and `for...yield` carry a break value:

- `loop { break v }` evaluates to `v`.
- `for x in items yield e` collects into a list; a `break v` adds a final element.

`while...do` and `for...do` iterate purely for side effects and always have type
`void`, so a value attached to `break` has nowhere to go.

## Fix

Use `loop { }` when the loop must produce a value:

```ori
let result = loop {
    if done then break 5
}
```

Or drop the value and carry the result in a mutable binding:

```ori
let result = 0;
while cond do {
    if done then break
}
```
