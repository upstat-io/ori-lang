# E2056: Undeclared Fixed-List Capacity Const

A fixed-list capacity references a name that is not declared as a const in the
current lexical scope.

```ori
@bad<$N: int> (items: [int]) -> void = {
    let bounded: [int, max M] = items;  // error: M is undeclared
}
```

Declare the capacity in the generic parameter list or use a declared const:

```ori
@good<$M: int> (items: [int]) -> void = {
    let bounded: [int, max M] = items;
}
```

See Spec Clauses 8.2.2 and 8.3.1.
