# E0015: Reserved-Future Keyword Used as an Identifier

An identifier uses a word reserved for a future version of Ori. Reserved words
cannot name a binding or declaration.

## Fix

Rename the identifier. A reserved word may still appear after `.` as a member
name where the grammar permits member access.
