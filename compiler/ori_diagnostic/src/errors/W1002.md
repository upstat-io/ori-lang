# W1002: Unknown Calling Convention

An `extern` block names a calling convention other than `"c"` or `"js"`.
Compilation continues, but the convention is not recognized.

## Fix

Use `"c"` for C-compatible foreign functions or `"js"` for JavaScript host
functions, and correct any spelling or capitalization difference.
