# E0010: Increment Operator

The source uses `++`. Ori does not define a C-style increment operator.

Adjacent `-` characters remain separate unary or binary minus operators, so
`--x` is the double negation `-(-x)` rather than a decrement operator.

## Fix

Use an explicit assignment such as `count = count + 1`. For an immutable `$`
binding, compute a new value instead of assigning to it.
