# E0010: Increment or Decrement Operator

The source uses `++` or `--`. Ori does not define C-style increment or
decrement operators.

## Fix

Use an explicit assignment such as `count = count + 1` or
`count = count - 1`. For an immutable `$` binding, compute a new value instead
of assigning to it.
