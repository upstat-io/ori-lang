# E0911: Unsupported Fractional Duration or Size Literal

E0911 is a tracked, non-emitted compatibility code whose stable historical
meaning was that floating-point `Duration` or `Size` literal syntax was
unsupported. Current Ori accepts decimal unit literals when they resolve to
whole nanoseconds or bytes; non-representable literals use E0014. No current
source triggers E0911.

## Fix

For source from a compiler version that emitted E0911, express the value with a
unit that produces a whole number of nanoseconds or bytes, or use an explicit
`Duration` or `Size` constructor.
