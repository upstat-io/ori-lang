# E3010: Function Has No Tests

A function declaration has no associated test when test enforcement is active.

## Example

```ori
@add (a: int, b: int) -> int = a + b    // E3010: function `@add` has no tests
```

## Explanation

When test enforcement is set to `"error"` or `"warn"`, the compiler checks that
every function declaration (except `@main`) has at least one test targeting it
via the `tests @target` syntax.

## Solutions

1. **Add a test:**
   ```ori
   @add (a: int, b: int) -> int = a + b

   @test_add tests @add () -> void = {
       use std.testing { assert_eq };
       assert_eq(add(a: 1, b: 2), 3);
   }
   ```

2. **Adjust enforcement level:**
   ```bash
   ori check --test-enforcement=off file.ori
   ```
