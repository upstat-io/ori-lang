# E2041: Invalid `#repr` Attribute

A `#repr` attribute was applied with invalid parameters or to an incompatible type.

## Common causes

### `#repr("transparent")` on wrong field count

`#repr("transparent")` requires exactly one field — the struct becomes a zero-cost wrapper:

```ori
// Error: zero fields
#repr("transparent")
type Empty = { }

// Error: two fields
#repr("transparent")
type Pair = { x: int, y: int }

// OK: one field
#repr("transparent")
type Wrapper = { inner: int }
```

### `#repr("aligned", N)` with invalid alignment

The alignment value must be a positive power of two:

```ori
// Error: 0 is not valid
#repr("aligned", 0)
type Bad = { value: int }

// Error: 3 is not a power of two
#repr("aligned", 3)
type AlsoBad = { value: int }

// OK: 8 is a power of two
#repr("aligned", 8)
type Good = { value: int }
```
