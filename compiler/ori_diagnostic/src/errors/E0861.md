# E0861: `continue` with Value in a Non-Collecting Loop

A `continue value` was used inside a loop form that does not accumulate values:
`loop { }`, `while...do`, and `for...do`.

## Example

```ori
loop {
    if skip then continue 42  // ERROR: loop does not collect values
}
```

```ori
while cond do {
    if skip then continue 0  // ERROR: while does not accumulate values
}
```

## Explanation

`continue value` is meaningful only in `for...yield`, where it substitutes the
value contributed for the current element:

```ori
for x in items yield {
    if x < 0 then continue 0;  // use 0 instead of skipping
    x
}
```

`loop`, `while`, and `for...do` do not build a collection, so a value attached
to `continue` has no destination.

## Fix

Drop the value — bare `continue` starts the next iteration in any loop:

```ori
loop {
    if skip then continue
}
```

Use `for...yield` when each iteration must contribute a value:

```ori
let mapped = for x in items yield {
    if skip(x) then continue 0;
    transform(x)
}
```
