# E5001: LLVM Module Verification Failed

The compiled LLVM module violated an LLVM IR invariant. Source that passes the
front end should not produce invalid IR, so this normally indicates a compiler
defect rather than an error in the Ori program.

## Fix

Keep the complete diagnostic, reduce the source to the smallest reproducer,
and report it at `https://github.com/upstat-io/ori-lang/issues` with the output
of `ori --version`.
