# E2039: Cannot Assign to Immutable Binding

An attempt was made to mutate a binding declared with `let $` (immutable).

## Example

```ori
let $x = 42
x = 100  // ERROR: cannot mutate immutable binding `x`
```

## Explanation

In Ori, `let $` creates an immutable binding — the value cannot be changed
after initialization. `let` (without `$`) creates a mutable binding.

The `$` prefix signals a deliberate choice to make the binding immutable,
providing stronger guarantees about value stability throughout its scope.

## Fix

Remove the `$` prefix to make the binding mutable:

```ori
let x = 42
x = 100  // OK: `let` bindings are mutable
```

Or restructure the code to avoid mutation:

```ori
let $x = 42
let $y = x + 58  // use a new binding instead
```
