# E4003: ARC Internal Error

An internal invariant was violated during ARC analysis or lowering.

## Explanation

This error indicates a bug in the ARC optimization pipeline. The compiler
detected an inconsistency in its internal data structures during reference
counting analysis, borrow inference, or IR lowering.

## Fix

This is an internal compiler error. Please report it with the source file
that triggered the error. As a workaround, simplifying the affected function
may avoid the problematic code path.
