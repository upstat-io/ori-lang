# E0014: Decimal Unit Literal Is Not Exactly Representable

A decimal duration or size literal cannot be represented as a whole number of
its base units: nanoseconds for `Duration` or bytes for `Size`.

## Fix

Choose a unit or value that converts exactly to whole nanoseconds or bytes. For
values computed at runtime, use the corresponding `Duration` or `Size`
constructor and handle rounding explicitly.
