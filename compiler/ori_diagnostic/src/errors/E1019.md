# E1019: Invalid Trait Implementation Form

A trait implementation uses the foreign-language form `impl Trait for Type`.
Ori writes the implemented type first.

## Fix

Rewrite `impl Trait for Type` as `impl Type: Trait`.

- `docs/ori_lang/v2026/spec/grammar.ebnf` - `trait_impl`
