# E2058: Module Constant Could Not Be Evaluated

A module-level constant must produce a compile-time value before executable
code is lowered. This error means its initializer has a dependency cycle,
refers to an unavailable constant, traps during arithmetic, or uses an
expression outside the currently supported constant-value domain.

```ori
$timeout = 30 / 0; // error: constant evaluation divides by zero
```

Rewrite the initializer so it depends only on available constants and supported
compile-time operations. For arithmetic failures, use operands that do not
overflow and a non-zero divisor. For an imported constant, compile the provider
module directly and fix its reported constant error first.

```ori
$timeout = 30 / 1;
```

See Spec Clause 24.
