# E6040: Non-Exhaustive Match at Runtime

E6040 is a dormant runtime-invariant category for a `match` reaching no arm. No
current producer constructs E6040; the evaluator's present fallback is a custom
E6099 error. Well-typed Ori source must be exhaustive.

## Fix

If this code is emitted for well-typed source, report the source, full
diagnostic, and `ori --version` at
`https://github.com/upstat-io/ori-lang/issues`.

- `docs/ori_lang/v2026/spec/15-patterns.md` - exhaustive matching
