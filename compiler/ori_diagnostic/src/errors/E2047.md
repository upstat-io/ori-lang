# E2047: Pre-Condition Contract References Unknown Identifier

A `pre(condition)` clause referenced a name that is not in scope at the
contract's evaluation point. Pre-conditions are evaluated on function entry
with a restricted environment — only function parameters and module-level
bindings are visible.

## Cause

Local bindings introduced inside the function body do not exist when `pre()`
runs:

```ori
let $threshold = 100

@process (input: int) -> int
    pre(input > threshold)       // OK — `input` is a parameter, `threshold` is module-level
    pre(input > scratch)         // E2047 — `scratch` is not in scope
    = {
        let scratch = compute()
        input + scratch
    }
```

The scope check runs before the type check, so `pre()` clauses that reference
unknown names fail with E2047 even if the rest of the contract would also
fail E2044 once the unknown name was resolved.

## Cure

Reference only function parameters and module-level constants from `pre()`,
or move the dependent computation into the function and use a runtime
`assert()` instead:

```ori
let $threshold = 100

@process (input: int) -> int
    pre(input > threshold)            // module-level constant — OK
    = {
        let scratch = compute()
        assert(input > scratch)       // body-local check via assert
        input + scratch
    }
```
