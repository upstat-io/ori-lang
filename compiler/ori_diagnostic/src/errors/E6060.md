# E6060: Missing Capability at Runtime

E6060 is a dormant runtime category for a required capability with no active
provider. No production path currently constructs it; capability declaration
and provision errors are normally rejected before execution.

## Fix

Declare the capability in the function's `uses` clause and ensure the caller
provides it through `with` or an applicable default implementation.
