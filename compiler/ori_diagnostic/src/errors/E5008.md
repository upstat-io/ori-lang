# E5008: WebAssembly Code Generation Failed

WebAssembly-specific configuration, JavaScript binding generation, TypeScript
declaration generation, or output writing failed.

## Fix

Check that the selected WebAssembly target supports the requested output. If
the program is valid for that target, report the source, complete diagnostic,
target, and `ori --version` at
`https://github.com/upstat-io/ori-lang/issues`.
