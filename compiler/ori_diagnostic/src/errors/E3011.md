# E3011: Test Targets Unknown Function

A test declaration references a function via `tests @target` that does not exist
in the current module.

## Example

```ori
@test_add tests @add () -> void = {    // E3011: test targets unknown `@add`
    use std.testing { assert_eq };
    assert_eq(1 + 2, 3);
}
```

## Explanation

The `tests @target` syntax creates a compiler-tracked link between a test and
the function it covers. If the target function name does not match any function
in the current module, this error is reported.

## Solutions

1. **Check the function name:**
   ```ori
   @addition (a: int, b: int) -> int = a + b

   // Wrong: targets @add, but function is @addition
   @test_add tests @addition () -> void = {
       use std.testing { assert_eq };
       assert_eq(addition(a: 1, b: 2), 3);
   }
   ```

2. **Use a floating test** if the test is not specific to one function:
   ```ori
   @integration_test tests _ () -> void = {
       // tests that exercise multiple functions
   }
   ```
