# E2054: Use of a Binding After `drop_early`

`drop_early(value: x)` consumes `x` and runs its drop immediately. After the
call the binding `x` is inaccessible — any subsequent use is a compile-time
error, because the value's memory has already been reclaimed and reading it
would be a use-after-free.

Spec: Clause 13 §13.7 (Variable Lifetime) — "After `drop_early(value: x)`, the
binding `x` is inaccessible; any subsequent use is a compile-time error."

```ori
{
    let file = open_file(path: "data.txt");
    let content = read_all(file);
    drop_early(value: file);  // `file` is consumed here
    process(file);            // error[E2054]: use of `file` after `drop_early`
}
```

The fix: use the value before `drop_early`, or remove the later use. If you
need the value after this point, do not drop it early — let it drop at the end
of its scope.

```ori
{
    let file = open_file(path: "data.txt");
    let content = read_all(file);
    process(content);         // use `content`, not the dropped `file`
    drop_early(value: file);  // drop `file` after its last use
}
```

A value re-bound after the drop (`let file = open_file(...)` shadowing the
consumed binding) is a fresh binding and is accessible again.
