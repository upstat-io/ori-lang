# E4002: Unsupported Pattern in ARC IR Lowering

A pattern kind was encountered during ARC IR lowering that does not yet
have a lowering implementation.

## Explanation

The ARC pass compiles pattern matches into decision trees. Some pattern forms
may not yet be supported in the ARC IR lowering path. This is an internal
limitation — the pattern passed type checking but cannot be compiled.

## Fix

This is a compiler limitation. Consider restructuring the pattern match
to use simpler patterns. Please report the issue if you encounter this
error in normal code.
