# E0012: Detached Doc Comment

A documentation comment is not immediately attached to a declaration, so it
cannot document the item the author likely intended.

## Fix

Move the comment directly before the function, type, trait, implementation, or
other declaration it documents. If it is ordinary commentary rather than API
documentation, relocate or remove it.
