# E6051: Explicit Panic

E6051 is a dormant structured category reserved for an explicit `panic(msg:)`.
No production path currently constructs it; the evaluator reports the present
panic path as custom E6099.

## Fix

Use the panic message and stack trace to locate the failed invariant. Use
`Result` instead when the condition is recoverable.
