# E2050: Type Does Not Support Index Assignment

An `x[i] = v` index assignment targeted a type that supports index *reads* but
not index *assignment*.

## Example

```ori
let s = "abc"
s[0] = "x"  // ERROR: `str` does not support index assignment
```

## Explanation

`str` is immutable through indexing: `s[i]` reads a single-codepoint `str`, but
there is no `IndexSet` operation to write through an index. Only types with a
mutable indexed-storage operation (such as `[T]` and `{K: V}`) may appear as the
receiver of an index assignment.

## Fix

Build a new value instead of mutating through the index — for a string, assemble
the result from slices or a list of characters and re-bind it:

```ori
let s = "abc"
let s2 = "x" + s.substring(start: 1, end: s.len())  // OK
```
