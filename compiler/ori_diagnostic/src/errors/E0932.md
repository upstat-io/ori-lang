# E0932: Invalid Feature Name

A conditional-compilation feature name is not a valid Ori identifier. Feature
names must start with a letter or underscore and contain only letters, digits,
and underscores.

## Fix

Rename the feature and update each conditional attribute that refers to it.
For example, replace a hyphen with an underscore.
