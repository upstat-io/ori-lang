# W1001: Detached Doc Comment

A documentation comment is separated from the declaration it appears to
describe, so it will not be attached to that item.

The parser-warning adapter and producer method exist, but no production path
currently calls `check_detached_doc_comments`; lexer-stage detached-comment
warnings use E0012.

## Fix

Move the comment immediately before the declaration. If the text is not API
documentation, use a regular `//` comment instead.
