# E4001: Unsupported Expression in ARC IR Lowering

An expression kind was encountered during ARC IR lowering that does not yet
have a lowering implementation.

## Explanation

The ARC (Automatic Reference Counting) pass converts the typed expression tree
into a basic-block intermediate representation. Some expression forms may not
yet have lowering support. This is an internal limitation, not a user error —
the expression passed type checking but cannot be compiled through the ARC
pipeline.

## Fix

This is a compiler limitation. Consider simplifying the expression or
restructuring the code to avoid the unsupported pattern. Please report
the issue if you encounter this error in normal code.
