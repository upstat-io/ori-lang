# E6030: Function Arity Mismatch

A function or method call supplied a different number of arguments from the
callable's parameter list.

## Fix

Supply the required number of arguments. Direct calls use named arguments as
specified in section 14.1.3, while calls through function values use positional
arguments.

- `docs/ori_lang/v2026/spec/14-expressions.md` - section 14.1.3
