# E2043: Conditional Partial Move Not Statically Computable

A non-Drop aggregate was partially moved on one CFG path but not the other,
producing a per-path `moved_out_fields` bitset that requires fixpoint dataflow
to resolve. Phase 5 ARC lowering relies on the invariant that
`moved_out_fields[v]` is statically computable per-CFG-path; conditional
partial moves violate this invariant and MUST be rejected at type-check time.

## Cause

Conditional partial-move patterns appear when a field is projected on one
branch but not the corresponding branch:

```ori
type Pair = { left: str, right: str }     // non-Drop aggregate

@example (cond: bool, v: Pair) -> str = {
    if cond then {
        let l = v.left      // partial move of `v.left`
        l
    } else {
        ""                  // no move of `v.left`
    }
    // After the if: was `v.left` moved? Depends on `cond` at runtime.
}
```

At the join point, `moved_out_fields[v]` differs per predecessor: one path
shows `{0}` (left moved); the other shows `{}` (no moves). Computing the
join requires fixpoint dataflow over a lattice — explicitly out of scope
for Phase 5 trivial emission per the §03 goal ban on "global flow analysis,
fixpoint, lattice consultation".

## Cure

Allowed partial-move patterns are statically computable: direct field
projection on every path through the aggregate's scope, OR match
destructuring that uniformly consumes the same field set. Restructure the
code so the field projection is unconditional, or move the aggregate
into the conditional and project inside each branch independently:

```ori
// Cure 1: unconditional projection before the branch
@example (cond: bool, v: Pair) -> str = {
    let l = v.left      // unconditional partial move — statically computable
    if cond then l else ""
}

// Cure 2: move-then-branch (full ownership transfer)
@example (cond: bool, v: Pair) -> str = {
    if cond then v.left else v.right
    // Each branch projects exactly one field; match-destructuring semantics
    // make the per-branch move set statically computable.
}
```

If the conditional partial move is essential to the algorithm, the
aggregate's type SHOULD implement `Drop` — Drop types follow `EDROP_PARTIAL_MOVE`
(E2044, reserved) semantics where the compiler emits drop glue for
non-moved fields at scope exit. For non-Drop types, conditional partial
moves are rejected to keep Phase 5 emission trivial.
