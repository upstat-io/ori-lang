# E6010: Runtime Type Mismatch

E6010 is a dormant structured-runtime category for an evaluator value whose
runtime type contradicts the operation's required type. No production evaluator
path currently constructs it. If emitted, it indicates a compiler
phase-consistency defect rather than an ordinary source-level type error.

## Fix

Report the source, full diagnostic, and `ori --version` at
`https://github.com/upstat-io/ori-lang/issues`; do not work around a type error
that the compiler should have rejected before execution.
