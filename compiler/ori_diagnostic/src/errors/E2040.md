# E2040: Feature Not Yet Supported

A language feature was used that is recognized by the compiler but not yet
implemented.

## Example

This error appears when valid Ori syntax references a feature that is planned
but not yet available in the current compiler version.

## Explanation

The Ori compiler recognizes certain syntax and constructs that are part of the
language specification but have not yet been implemented. This error is used
as a placeholder until the feature is available.

## Fix

Check the Ori language specification and release notes for the current set of
supported features. The feature may become available in a future release.
