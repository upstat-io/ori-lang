# E1020: Invalid Assignment Target

The left-hand side of an assignment is not a valid assignment target. An
assignment target must be an identifier, optionally followed by `[index]` or
`.field` accessors.

## Example

```ori
@update (items: [int]) -> void = run(
    f()[0] = 1,          // Error: the root must be an identifier, not a call
    (a + b)[0] = 1,      // Error: the root must be an identifier, not an expression
    obj.method() = 1,    // Error: a method call is not an assignment target
    (a as int).f = 1,    // Error: a cast is not an assignment target
)
```

## Explanation

A valid assignment target is a chain rooted at a single identifier, followed by
zero or more index (`[expr]`) or field (`.name`) accessors:

```ori
x = 1            // identifier
x[i] = 1         // identifier + index step
state.field = 1  // identifier + field step
grid[i][j] = 1   // identifier + nested index steps
state.items[i].name = 1  // identifier + mixed field/index steps
```

The root must be a bare identifier so the compiler knows which binding is being
updated. Calls, casts, parenthesized expressions, the `?` operator, and other
non-accessor postfix forms are rejected because they do not name a binding that
can be reassigned.

## Fix

Bind the receiver to an identifier first, then assign through it:

```ori
let target = f();
target[0] = 1;
```
