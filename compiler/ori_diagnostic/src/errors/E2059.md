# E2059: Invalid Fixed-List Capacity Expression

A fixed-list capacity is not an evaluable integer expression. Capacities may
use integer literals and declared integer consts with `+`, `-`, `*`, `/`, `%`,
`&`, `|`, `^`, `<<`, or `>>`.

```ori
let invalid: [int, max true] = []; // error: bool is not an integer capacity
```

Use a positive integer literal or an allowed expression over declared integer
const parameters and bindings. Arithmetic overflow, division or modulo by zero,
and invalid shift counts are also rejected.

See Spec Clauses 8.2.2 and 8.3.1.
