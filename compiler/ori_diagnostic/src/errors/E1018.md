# E1018: Untyped Parameter in Typed Lambda

A lambda mixes typed and untyped parameters. Once one parameter is annotated,
every parameter in that lambda must have a type.

## Fix

Add a type to every parameter, such as `(a: int, b: int) -> a + b`, or remove
all parameter annotations and let the lambda types be inferred.
