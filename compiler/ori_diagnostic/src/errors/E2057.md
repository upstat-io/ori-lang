# E2057: Fixed-List Capacity Must Be Positive

A fixed-list capacity was evaluated to zero or a negative integer. Fixed-list
capacities shall be positive compile-time integers.

```ori
let zero: [int, max 0] = [];      // error
let negative: [int, max -1] = []; // error
let valid: [int, max 1] = [];     // OK
```

Use a capacity greater than zero. See Spec Clause 8.2.2.
