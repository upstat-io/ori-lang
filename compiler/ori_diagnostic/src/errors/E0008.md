# E0008: Triple-Equals Operator

The source uses `===` or `!==`. Ori has no coercive or strict-equality variant;
equality is written with `==` and inequality with `!=`.

## Fix

Replace `a === b` with `a == b`, or replace `a !== b` with `a != b`. Ensure the
operands have compatible types rather than relying on implicit conversion.
