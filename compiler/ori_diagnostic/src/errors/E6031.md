# E6031: Stack Overflow

Evaluation exceeded the supported call-stack depth, usually because recursion
did not reach its base case or the input nesting is too deep.

## Fix

Verify the recursive base case and reduce recursion depth. Rewrite the
algorithm as a loop when it does not require recursive structure.
