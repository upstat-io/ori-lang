# E6070: Constant-Evaluation Budget Exceeded

E6070 is a dormant structured category for exceeded constant-evaluation limits.
No current path constructs it; current budget exhaustion is reported as custom
E6099.

## Fix

Simplify the constant expression, reduce its input, or move work that need not
be constant into normal runtime code.

- `docs/ori_lang/v2026/spec/24-constant-expressions.md` - sections 24.4 and 24.4.1
