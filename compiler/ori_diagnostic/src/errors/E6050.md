# E6050: Assertion Failed

E6050 is a dormant structured category for a failed assertion predicate or
expected relation, including `assert`, `assert_eq`, and `assert_ne`. No current
production path constructs it.

## Fix

Inspect the values reported by the assertion and correct either the program
behavior or the asserted expectation.
