# E1017: Missing Equals in Typed Lambda

E1017 is a reserved compatibility code for an explicit-return typed lambda
missing the `=` delimiter. The current parser does not emit it: after `->`, an
explicit return type is recognized only when immediately followed by `=`.

## Fix

Write an explicitly typed lambda as `(x: int) -> int = x + 1`. If the return
type should be inferred, omit the explicit return type and use the inferred
lambda form.
