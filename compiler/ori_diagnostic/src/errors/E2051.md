# E2051: Cannot Assign Through a Parameter Binding

A `p[i] = v` or `p.f = v` assignment targeted a parameter binding. Parameters
are not mutable roots for index or field assignment.

## Example

```ori
@mutate (p: [int]) -> int = {
    p[0] = 9  // ERROR: cannot assign through parameter `p`
    p[0]
}
```

## Explanation

Index and field assignment desugar to a re-binding of the assignment root
(`p = p.updated(key: i, value: v)` / `p = { ...p, f: v }`). A parameter is not a
mutable local, so the root cannot be re-bound. This mirrors the rejection of
assignment through an immutable `let $` binding (E2039), with a message naming
the parameter.

## Fix

Bind a mutable local from the parameter and assign through it, returning the new
value:

```ori
@mutate (p: [int]) -> [int] = {
    let xs = p
    xs[0] = 9  // OK: `xs` is a mutable local
    xs
}
```
