## 01.2 Move Playground WASM

**File(s):** `ori_lang/website/playground-wasm/` → `ori-lang-website/playground-wasm/`

The WASM playground is a standalone Cargo workspace that compiles the Ori compiler to WebAssembly. It has path dependencies into the compiler crates.

- [ ] Copy `playground-wasm/` directory (excluding `target/` and `pkg/`)
- [ ] Copy `playground-wasm/Cargo.toml`, `playground-wasm/Cargo.lock`, `playground-wasm/src/lib.rs`, `playground-wasm/.cargo/config.toml`
- [ ] Copy `playground-wasm/test_wasm.cjs`, `playground-wasm/test_wasm.js`, `playground-wasm/test_wasm.mjs` (WASM test harnesses)
- [ ] Verify the `[workspace]` declaration (standalone, not part of main workspace) is preserved
- [ ] Verify `playground-wasm/.cargo/config.toml` is included (contains `wasm32-unknown-unknown` target rustflags for 256MB stack size — required for deep recursion in tree-walking interpreter). This is already covered by the file list above but is critical enough to warrant explicit verification.
