# 2 Normative references

The following documents are referred to in the text in such a way that some or all of their content constitutes requirements of this document.

- **The Unicode Standard, Version 15.0** — Unicode Consortium. Character encoding and properties for `str` and `char` types.

- **IEC 60559:2020** — *Floating-point arithmetic*. Semantics of the `float` type.
