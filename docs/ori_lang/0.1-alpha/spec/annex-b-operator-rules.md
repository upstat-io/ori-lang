# Annex B (normative) — Operator rules

This annex defines the typing and evaluation rules for all operators in the Ori language. Each operator entry specifies:

- the operator symbol and name;
- operand types and type constraints;
- the result type;
- evaluation semantics, including edge cases and error conditions.

The complete operator rules are maintained in a companion file: [operator-rules.md](operator-rules.md)
